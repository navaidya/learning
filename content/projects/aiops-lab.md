# AIOps Lab

## Objective

Build a safe evidence-to-hypothesis workflow for Kubernetes incidents.

## Architecture

Signals flow into a read-only analysis step that produces cited observations and an approval-gated action proposal.

## Milestones

- Collect evidence
- Detect a bounded failure pattern
- Record an operator-reviewed recommendation

## Learning outcomes

Practice telemetry correlation, incident reasoning, and operational guardrails.
