# Passport renewal — child, age 16

Child-specific notes on top of the
[shared San Francisco process](../2026-09-02-passport-renewal-process-sf/),
now reconciled against the actual VFS minor checklist you sourced. Being
16 (in the 15–18 bracket) means there's a validity choice — this child is
getting the **full 10-year passport** instead of the until-age-18 minor
passport.

## What's different for 15–18

- **Validity**: chosen as the **full 10-year passport** (adult-style
  validity, still a 36-page booklet — that size is fixed regardless of
  validity chosen).
- **Police verification (PV)**: normally mandatory for the 10-year
  option at this age, **but** there's a standing exception for NRI
  minors 15–18 living abroad: **PV can be waived if either parent holds
  a valid Indian passport** — true here. This is not automatic — request
  it explicitly when filling the application (look for a PV-exemption /
  NRI-minor declaration option), and call VFS (+1 800 320 9625) before
  mailing if you don't see it on the form.
- **If PV can't be waived for any reason**: it adds real time on top of
  the normal 3-week estimate, so don't book travel around a fixed date
  until VFS confirms which path this application is on.
- **Still needs both-parent consent**: Annexure D is required regardless
  of age, since the applicant is still a minor under 18.
- **Signature**: the 16-year-old signs the application, Annexure E, and
  the appearance affidavit themselves — no thumb impression (that option
  is only for children under 5).
- **TATKAAL**: not being used for this application — going through the
  normal process by mail.

## Locked-in for this child

- Consent: **Annexure D**, both parents' signatures (notarize anyway,
  even though the checklist only explicitly requires it if a parent
  signs from abroad).
- Applicant's declaration: **Annexure E**, signed by the child.
- **Affidavit for Change in Appearance & Signature**: signed by the
  child — mandatory regardless of whether appearance actually changed.
- Proof of address: parent's **California driving license** — plain
  color copy, not notarized.
- Proof of the child's US status: **I-797A approval notice** — notarized
  color copy. (No I-94 needed.)
- Proof of parents' own US status: each parent's own **I-797A approval
  notice** — notarized color copy.
- **Birth certificate**: child's Indian birth certificate — plain copy.
- Submission: **mail-in** — no VFS appointment.
- Validity: **full 10-year passport**, 36-page booklet, PV-exemption
  requested (parents hold valid Indian passports).
- Fee/courier: pay online; enclose a prepaid return courier label
  (yours, or VFS's own) whose return address matches the application.

## Checklist

- [ ] Fill the application at `https://mportal.passportindia.gov.in/mission/`
      — select the correct jurisdiction, choose **"Re-issue"**, booklet
      type **"36 pages"**, the **full 10-year** validity option, and
      enter both an Indian and a US address.
- [ ] Look for the PV-exemption / NRI-minor declaration option on the
      form and select it; if it's not there, call VFS before mailing to
      confirm how to request the exemption.
- [ ] Upload the photo and signature on that portal before submitting —
      the application is returned unprocessed otherwise.
- [ ] Note the **ARN** generated — it must match the VFS payment
      receipt later.
- [ ] Get Annexure D signed by both parents.
- [ ] Get Annexure E filled and signed by the child.
- [ ] Get the Affidavit for Change in Appearance & Signature filled and
      signed by the child.
- [ ] Get the driving license color-copied (no notary needed).
- [ ] Get the child's I-797A approval notice copied in color and
      notarized.
- [ ] Get each parent's own I-797A approval notice copied in color and
      notarized.
- [ ] Get both parents' Indian passports (first/last pages) copied, each
      parent self-attesting their own copy.
- [ ] Get a plain copy of the child's Indian birth certificate.
- [ ] Take 2 photos to spec (35mm × 45mm, white background, identical,
      within 6 months).
- [ ] Gather the current passport — **original** — plus a copy of its
      first/last pages.
- [ ] Register on the VFS site, confirm the ARN matches, and pay the
      fee (~US$188 total, estimated — higher than the 5-year option
      since the 10-year choice is billed at the adult rate; confirm
      exact amount at checkout, and money order/banker's check must be
      payable to "VFS Services (USA) Inc." if not paying by card).
- [ ] Arrange the return courier label (yours or VFS's), matching the
      application's return address.
- [ ] Print the completed application and have the 16-year-old sign it
      (both parents also sign the last page), then assemble the mail-in
      package using the **final packing checklist** below.
- [ ] Mail to: VFS Global – San Francisco Center, 642 Harrison Street,
      Suite 200, San Francisco, CA 94107.
- [ ] Track status online; respond promptly if anything further is
      requested.
- [ ] Passport received — verify name, DOB, photo, and that the validity
      is the full **10 years** (not accidentally issued as 5-year/till-18)
      before putting it away.

## Final packing checklist — use this last, right before sealing the envelope

All 12 mandatory items, grouped by category exactly as the VFS checklist
marks them. The parents' I-797A copies below also serve as the
PV-exemption evidence, so no extra document is needed for that.

### Original (items 1, 2, 4, 5, 6, 12)

- [ ] 1. Application form, printed and signed (child + both parents on
      the last page)
- [ ] 2. Two photographs to spec (one already affixed to the
      application, one to the appearance affidavit)
- [ ] 4. Affidavit for Change in Appearance & Signature, signed by the
      child
- [ ] 5. Annexure E, signed by the child
- [ ] 6. Annexure D, signed by both parents
- [ ] 12. Fee payment confirmation receipt + prepaid return courier
      label

### Original + copy (item 3)

- [ ] 3. Current/expiring Indian passport — the physical booklet
- [ ] 3. Copy of the passport's first and last (bio & family) pages

### Notarized color copy (items 7, 10)

- [ ] 7. Child's I-797A approval notice
- [ ] 10. Parent 1's I-797A approval notice
- [ ] 10. Parent 2's I-797A approval notice

### Color copy — not notarized (item 8)

- [ ] 8. Parent's California driving license

### Self-attested copy (item 9)

- [ ] 9. Parent 1's Indian passport (first/last pages), self-attested
- [ ] 9. Parent 2's Indian passport (first/last pages), self-attested

### Plain copy (item 11)

- [ ] 11. Child's Indian birth certificate

### Before you seal it

- [ ] Count against the numbered list above: all 12 items present, each
      in the right category (don't notarize items 8/9/11 — they don't
      need it; don't skip notarizing 7/10 — they do).
- [ ] Envelope addressed to: VFS Global – San Francisco Center, 642
      Harrison Street, Suite 200, San Francisco, CA 94107.
